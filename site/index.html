THE PRINCIPLE

เริ่มจาก API
แล้วค่อยเลือกวิธีที่เหมาะสม

เรียนรู้ตั้งแต่ HTTP และ HTML ไปจนถึงการจัดการ error, schema, testing, Windows automation และ GitHub CI โดยใช้ local fixture เป็นค่าเริ่มต้นเพื่อให้ทดลองซ้ำได้โดยไม่ยิงเว็บไซต์จริง

THE ROADMAP

15 phases จากพื้นฐานถึง release

01—05

Web Foundations

Python, HTTP, API-first, static scraping, pagination และ downloads

06—10

Production Patterns

Playwright, Selenium, resilience, ethics, data pipeline และ export

11—15

Operate & Share

Testing, use cases, scheduling, GitHub CI, final review และ deployment

SAFE BY DEFAULT

ไม่ฝัง Secret

มี security policy, secret scan, rate-limit guidance และ checklist ก่อนใช้แหล่งข้อมูลจริง

READY TO TEST

Fixture-first

มี tests, mock HTTP, parser contracts และ CI เพื่อจับ schema/selector ที่เปลี่ยน

BUILT FOR WINDOWS

Run ได้จริง

มี PowerShell runner, Task Scheduler, log, exit code และ lock file สำหรับงานตามเวลา
