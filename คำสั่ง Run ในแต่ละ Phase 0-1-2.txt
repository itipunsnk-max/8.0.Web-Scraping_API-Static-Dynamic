#################################################
-----------------------------------------------------------

ตรวจสอบงาน Phase ก่อนหน้าทั้งหมดก่อน แล้วดำเนินการเฉพาะ Phase 1 ตาม ROADMAP.md

ข้อกำหนด:
- อย่าทำ Phase อื่นล่วงหน้า
- อย่าลบงานเดิม
- ตรวจสอบไฟล์ก่อนแก้ไข
- รัน Test, Lint หรือคำสั่งตรวจสอบที่เกี่ยวข้อง
- แก้ Error ที่พบในขอบเขตของ Phase นี้
- อัปเดต README และสารบัญเมื่อจำเป็น
- สรุปไฟล์ที่เพิ่มและแก้ไข
- ระบุคำสั่งทดสอบบน Windows PowerShell
- เสนอ Git commit message
- หยุดหลังจบ Phase นี้

เปลี่ยน Phase 1 เป็น Phase 2, Phase 3 ไปตามลำดับในแต่ละครั้ง


#################################################
Prompt สำหรับตรวจสอบงานหลังแต่ละ Phase
#################################################
-----------------------------------------------------------

ทำหน้าที่เป็น Code Reviewer และ Technical Documentation Reviewer

ตรวจสอบงานใน Repository สำหรับ Phase ล่าสุด โดยยังไม่เพิ่ม Feature ใหม่

ตรวจสอบหัวข้อต่อไปนี้:
1. Code รันได้หรือไม่
2. Import และ Path ถูกต้องหรือไม่
3. Dependencies ครบหรือไม่
4. คำสั่ง Windows PowerShell ถูกต้องหรือไม่
5. ตัวอย่างเหมาะกับผู้เริ่มต้นหรือไม่
6. มี Error Handling และ Timeout หรือไม่
7. มีการจำกัด Request หรือไม่
8. มี Secret หรือข้อมูลอ่อนไหวหรือไม่
9. มีการใช้ API ก่อน Scraping หรือไม่
10. ตัวอย่างละเมิด Terms, Privacy หรือ Access Control หรือไม่
11. Markdown link ภายในเสียหรือไม่
12. Tests ครอบคลุม Parser และ Export หรือไม่
13. มี Code ซ้ำที่ควรแยกเป็น Utility หรือไม่
14. หน้าเว็บเปลี่ยนแล้วระบบจะตรวจพบหรือไม่
15. README และ ROADMAP ตรงกับงานจริงหรือไม่

ให้แก้เฉพาะปัญหาที่ตรวจพบใน Phase ล่าสุด จากนั้น:
- รัน Test และ Lint
- สรุปปัญหาที่พบ
- สรุปสิ่งที่แก้
- ระบุปัญหาที่ยังแก้ไม่ได้
- เสนอ Commit message
- ห้ามเริ่ม Phase ใหม่
